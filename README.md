# Google Earth Engine (GEE) Geospatial Analysis Projects

This repository contains a collection of **Google Earth Engine (GEE)** scripts focused on environmental monitoring, land degradation analysis, and spatial decision support systems.

🌍 Overview

The projects in this repository apply Earth Observation data to study environmental dynamics such as desertification, biomass distribution, and multi-criteria spatial suitability analysis across Africa.

📂 Projects Included

🌵 Desertification Analysis
- Northern Nigeria
- Turkana County, Kenya  
Analyzes vegetation degradation trends using NDVI and land surface indicators to identify areas at risk of desertification.

🌱 Biomass Estimation
Estimates vegetation biomass using satellite-derived indices and geospatial modeling techniques for ecosystem assessment.

📊 Multi-Criteria Analysis (MCA)
Spatial decision support model integrating multiple geospatial layers to evaluate land suitability and environmental risk zones.
Data Sources

- Landsat 8 / 9
- Sentinel-2
- MODIS NDVI products
- Google Earth Engine public datasets

🛠️ Tools & Platform

- Google Earth Engine (JavaScript API)
- Remote Sensing techniques
- Spatial analysis workflows
- NDVI / spectral index computation

🎯 Purpose

The goal of these projects is to support environmental monitoring, land degradation assessment, and climate-related decision-making using scalable cloud-based geospatial processing.
